## Tints and Hints

Tints and Hints is a local color-clue party game inspired by Hues and Cues. One player gives a clue and others choose a color from the board. The browser demo runs this local game loop using SolidJS state.

The repository also contains a Node.js and Socket.IO multiplayer experiment. Multiplayer is disabled in the public demo, so the demo does not demonstrate connected sessions or server-synchronized gameplay.

Try the [local demo](https://tintsandhints.vercel.app/) or view the [source code](https://github.com/joecaro/tints-and-hints).
