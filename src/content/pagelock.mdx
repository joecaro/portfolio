# Page Lock

Page Lock is a React ownership UI library. It provides a context provider, a `usePageOwnership` hook, an owner badge, and a modal for claiming or releasing ownership. Storage adapters connect the components to local storage or an API supplied by the application.

## Updates and enforcement boundary

The library polls the adapter for ownership changes. With the default three-second interval, another user's change appears on the next poll. This is polling, not an immediate push update.

The React UI can display ownership and send lock or unlock requests through an adapter. It does not by itself guarantee mutual exclusion or prevent conflicting writes. For that, the backing service must enforce ownership atomically and reject writes from callers that do not hold the lock. The example and adapter interface show the client integration point; server enforcement depends on the application using the library.

## Integration example

```jsx
import {
  OwnershipProvider,
  createLocalStorageAdapter,
  OwnerBadge,
} from '@joecarot/page-lock';

const ownershipAdapter = createLocalStorageAdapter({ prefix: 'my-app' });
const userAdapter = {
  getCurrentUser: async () => ({
    id: 'user-123',
    email: 'user@example.com',
    name: 'Example User',
  }),
};
const config = { ownershipAdapter, userAdapter };

function App() {
  return (
    <OwnershipProvider config={config}>
      <OwnerBadge pageId="user-profile-123" />
    </OwnershipProvider>
  );
}
```

Page Lock is intended for React applications, including Next.js apps. Explore the [GitHub repository](https://github.com/joecaro/page-lock), [working example](https://github.com/joecaro/page-lock/tree/main/example), or [npm package](https://www.npmjs.com/package/@joecarot/page-lock).
