## Web Swinging Demo

I wanted to see how a superhero-style swing would feel using Unity physics. I wrote the controls in C#.

## Mechanics Overview

Attach a web to a marked surface and swing. Unity physics determines the arc, speed, and momentum.

### Key Features

- **Physics-Based Swinging**: The web swinging mechanic is driven by Unity's physics system, simulating gravity and momentum. Players can build speed by timing their swings and detaching at the right moment to reach farther distances.
- **Swing Feel**: I adjusted the physics to balance momentum with responsive controls.

- **Swing Points**: Players can attach the web to multiple marked surfaces.

## Tech Stack

- **Unity**: The project is built in Unity, leveraging its physics engine to create smooth, realistic web swinging mechanics.
- **C#**: I wrote the game logic and physics calculations in C#.

## What I Learned

I used Unity's physics system to apply forces and calculate momentum for the swing.
