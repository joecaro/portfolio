## 3D Flappy Bird Clone

This was my first Unity game and my first time writing C#. I made a 3D version of Flappy Bird and modeled the bird, pipes, and other assets in Blender.

## Why I Built It

I chose Flappy Bird because its simple mechanics let me focus on making the game and its assets in 3D.

## Features

- **3D Gameplay**: Unlike the original 2D version, this clone brings the game into a 3D environment, giving a fresh perspective to the classic gameplay.
- **Unity Physics**: Unity's physics engine handles the jump and obstacle movement.
- **Custom 3D Assets**: I modeled the bird and pipes in **Blender**.

![Flappy Bird Clone](https://res.cloudinary.com/joecarothers/image/upload/v1653009936/misc/Projects/Flappy_gif_small_avauxd.gif)

## Tech Stack

- **Unity**: Unity handles the physics.
- **C#**: I used C# for the game logic.
- **Blender**: I created all the 3D models and textures in Blender, giving me the opportunity to combine my passion for 3D modeling with game development.

## What I Learned

I used C# to script the game rules and Unity physics to handle movement and collisions.
