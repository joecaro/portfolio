## MTG Help Me

MTG Help Me is a Magic: The Gathering companion app with three main features: an AI chat for game questions, a card and rules lookup dictionary, and image generation for custom card concepts. The version documented here used OpenAI's `gpt-4o-mini` for chat and DALL·E 3 for image generation; the live deployment's current model configuration has not been rechecked.

The app also includes a password-protected area. The chat can provide suggestions and explanations, but it is not an authoritative source for current game rules.

Built with Next.js, React, TypeScript, and Radix UI. Visit the [demo](https://mtg-helper-two.vercel.app/) or browse the [GitHub repository](https://github.com/joecaro/mtg-helper).
