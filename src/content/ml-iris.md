## Neural Network Iris Test

I used Keras to train my first neural network in Python. It classifies iris flowers from four measurements.

## Why I Built It

In school I had used Orange Data Mining to run models on sample datasets. I wanted to write and train the model myself.

## Key Features

- **Keras Neural Network**: The model classifies the Iris dataset into Setosa, Versicolor, or Virginica.
- **Training and Testing**: The project includes scripts to train the network and evaluate it on a test set. I tried different layer counts, activation functions, and optimizers.
- **From Scratch**: I also built neural networks from scratch as a learning exercise.

## The Iris Dataset

The **Iris dataset** is a classic dataset in machine learning, containing 150 records of iris flowers, each with four features: sepal length, sepal width, petal length, and petal width. The dataset is often used to test classification models because of its simplicity and small size. The task is to classify the iris species based on these features.

## Tech Stack

- **Python**: The project is implemented in Python.
- **Keras**: I used **Keras** to build the network.
