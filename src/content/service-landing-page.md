## Service Landing Page

I built a one-page template for a service business using Next.js and CSS.

### Key Problems

1. **Single Page Website**: The business needed a one-page site to present its services.
2. **Scalability**: While the current version is a single page, the architecture needed to support future expansion into a multi-page site as the business grows.

### Solutions

1. **Next.js** generates the page at build time and gives the site a route structure if more pages are needed.
2. **Layout** keeps the services easy to find on one page.
3. **CSS** handles the styling without a UI framework.

## Tech Stack

- **NextJS**: The site uses Next.js for static generation and routing.
- **ReactJS**: Used for the interactive components and modular design structure.
- **HTML & CSS**: HTML and CSS define the page structure and styles.

See the [source code](https://github.com/joecaro/service-provider-landing-page) or [open the demo](https://servicelandingpage.netlify.app/).
